## Dependencias Python:
pip install flask pillow pypdf2 python-docx qrcode

## Instalación por SO:

Windows:
pip install flask pillow pypdf2 python-docx qrcode

Arch Linux:
sudo pacman -S python-pip
pip install flask pillow pypdf2 python-docx qrcode --break-system-packages

Ubuntu / Debian:
sudo apt update
sudo apt install python3 python3-pip -y
pip3 install flask pillow pypdf2 python-docx qrcode --break-system-packages

## Cloudflare Tunnel (opcional - acceso remoto):
Linux: https://github.com/cloudflare/cloudflared/releases
Arch: sudo pacman -S cloudflared
Uso: cloudflared tunnel --url http://localhost:5050

## Ejecutar:
python start.py
